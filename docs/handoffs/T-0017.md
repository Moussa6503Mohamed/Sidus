change to `vitest.config.ts` was needed in the end.

## Test changes and why

Three existing test files needed updates because the visible text/ARIA role they render changed
(explicitly permitted scope — "update component tests only where changed semantics require it"):

1. `app/dashboard/practice/workspace.test.tsx` — options are now `role="radio"`
   (`aria-checked`) instead of `role="button"` (`aria-pressed`) before marking; the two generic
   post-mark tags "Selected"/"Correct" became the spec's explicit per-state tags "Correct answer"
   and "Your answer · incorrect".
2. `app/dashboard/editorial/sources/workspace.test.tsx` — content-source status label is now
   "Pending review" (from `lib/design/status.ts`, matching the artifact's badge text) instead of
   the page-local "Pending".
3. `app/dashboard/editorial/questions/workspace.test.tsx` — rubric freshness text changed from
   bare "stale"/"current" to "Stale — content changed since review"/"Current revision"; the
   canonical marker changed from lowercase "canonical" to "Canonical" (and the assertion was
   scoped to the badge `<span>` since the table also has a "Canonical" column header).

New focused tests added: `lib/design/option-state.test.ts` (pure function, all six states),
`components/ui/StatusBadge.test.tsx` (every status renders an icon + visible label; draft is
dashed-bordered; retired is struck-through — i.e. never colour-only), and
`components/theme/ThemeToggle.test.tsx` (default/persisted-read/full cycle + `data-theme` +
`localStorage` side effects).

## Known gap (documented, not silently dropped)

Practice Mode's MCQ options are individually `Tab`-focusable native `<button>`s rather than a full
roving-tabindex radiogroup with arrow-key navigation between them, which the source artifact's
accessibility section describes as the target pattern. Click/Tab/Space/Enter all work correctly.
Implementing roving tabindex was deferred to avoid a larger change to existing keyboard-interaction
wiring within this pass — see `docs/sidus-observatory-design-system.md` "MCQ option states".
