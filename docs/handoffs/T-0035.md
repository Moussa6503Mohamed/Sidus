# T-0035 handoff — learning analytics foundation

**Status:** review

## Delivered

- Additive `0025_create_learning_analytics_events.sql`: append-only owner-bound outcome snapshots
  with database immutability trigger and per-attempt/event idempotency key.
- Core `GET /learner/analytics`, protected by existing learner attempt permission, with no caller
  filter or identifier.
- Deterministic attempt submission records a scored event atomically. Written work records pending
  atomically and terminal accepted/withheld events only after the existing marking lifecycle.
- Fixed learner BFF operation/route and a white-first Sidus dashboard with loading, error/retry,
  empty, pending/partial, and populated progress states.

## Privacy and scope

Analytics never includes answers, prompts, question ids, rubric/canonical answer data, source or
provenance, feedback, model/cost/trace fields, or another learner's data. No live AI/API call,
source material, seed, or human-review flow was added.

- Web Vitest, typecheck, and production build: pass.
