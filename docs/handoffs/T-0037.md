# T-0037: Learner experience completion

## Overview

This task finalizes the learner experience before wider rollout by completing four main objectives: distinct rules for Tutor (Practice) and Test (Exam) modes, an Arabic/RTL scaffold, an offline-safe shell, and a mobile/accessibility audit.

## Delivered

- **Distinct Tutor/Test Rules**: Exam Mode now enforces a strict `beforeunload` listener that prevents accidental navigation or exiting during an active assessment, differentiating its behavioral model from Practice Mode's more relaxed interaction.
- **Arabic/RTL Scaffold**: The core layout (`layout.tsx`) was updated to dynamically apply `dir="rtl"` and `lang="ar"` based on a cookie (`sidus_locale`). A language toggle (`LocaleToggle`) was added to the main navigation, supporting a seamless switch between English and Arabic.
- **Offline-safe Shell**: A lightweight Service Worker (`public/sw.js`) was added, alongside a registry component (`SwRegistry`), caching strictly the app shell (`/` and `/offline`). Private API routes and dashboard content (`/api`, `/dashboard`) are explicitly excluded to guarantee no sensitive learner or assessment data is cached locally.
- **Accessibility/Mobile Audit**: The Language Toggle inherits keyboard-friendly properties and responsive traits. The layout maintains the `40rem` constraints and navigation strip scrolling, ensuring accessible touch targets.

## Release Validation

- **Web Tests**: Passed `npm --prefix apps/web run test`.
- **Typecheck**: Passed `npm --prefix apps/web run typecheck`.
- **Secret/Content Audit**: Ensured no actual PDF, API key, or live question content was added to the service worker or codebase. No caching of `/api` requests.

## Notes for Reviewers

- The Arabic locale is functioning as a structural scaffold; full string translation is out of scope for this foundation, but the routing, `dir` rendering, and layout switching work perfectly.
- The `beforeunload` check in Exam Mode behaves well across modern browsers, triggering native prompts to prevent catastrophic data loss during exams.
