## Decisions / assumptions

- Existing source approval-required fields (`owner`, `title`, `sourceUrl`, `sourceHash`,
  `licenceReference`, `permittedUse`, `allowedAudience`) define machine-checkable completeness.
  Human review—not software—determines whether written evidence legally covers required uses.
- Historical null origin remains eligible under prior gates and cannot be changed later. New rows
  cannot be null through Core create.
- Licensed attempt feedback submission rechecks provenance gate because feedback is learner
  delivery. Existing original/historical pinned-attempt behavior is unchanged.
- No source content, licence value, or locator value enters audit arrays. Tests use opaque runtime
  scaffolding only; no real-world rights claim or copyrighted content was added.
