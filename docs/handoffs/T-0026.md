# T-0026 — Local Exam Mode MVP

## Status

Review. Implementation ready for commit locally; not pushed or released.

## Delivered

- New authenticated `/dashboard/exam` surface. Recognized roles only.
- Active-syllabus picker, optional opaque curriculum-node filter, and deterministic first-in-list
  selection of 2–10 eligible MCQs.
- One-at-a-time answer selection, Back/Next, flags, answered/flagged counts, and a 30-minute
  browser-local timer. Refreshing loses the in-memory exam; timer is not server-authoritative.
- Explicit submit confirmation. Answered questions finalize sequentially through existing learner
  create-attempt/submit-attempt routes. Unanswered questions create no attempt.
- Runtime retry keeps created attempt IDs and completed results, so current-page retries do not
  repeat a create or completed submit.
- Result review exposes only existing learner-safe marking response after finalization.

## Scope proof

- No Core, AI, database, migration, shared contract, BFF route, or Practice Mode file changed.
- No source, locator, provenance, licence, PDF, private path, fixture, seed, educational text, or
  credentials added.
- Existing learner BFF remains fixed-operation and is reused unchanged.
