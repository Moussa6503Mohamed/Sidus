# T-0026 — Local Exam Mode MVP

## Status

Review. Review fixes added locally; not pushed or released.

## Delivered

- New authenticated `/dashboard/exam` surface. Recognized roles only.
- Active-syllabus picker, optional opaque curriculum-node filter, and deterministic first-in-list
  selection of 2–10 eligible MCQs.
- One-at-a-time answer selection, Back/Next, flags, answered/flagged counts, and a 30-minute
  browser-local timer. Timer uses latest selected answers at expiry and continues while submit
  confirmation is open. Refreshing loses in-memory exam; timer is not server-authoritative.
- Explicit accessible submit confirmation: initial focus, Tab containment, and return focus to
  submit trigger on cancellation. Answered questions finalize sequentially through existing learner
  create-attempt/submit-attempt routes. Unanswered questions create no attempt.
- Runtime retry keeps created attempt IDs and completed results, so current-page retries do not
  repeat a create or completed submit.
- Result review exposes only existing learner-safe marking response after finalization. Its
  aggregate is labelled **Answered score** because unanswered questions create no attempt and do
  not expose a trustworthy maximum mark.

## Scope proof
